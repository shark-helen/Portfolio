# Описание проекта

Необходимо провести анализ и рассчитать ключевые метрики активности пользователей сервиса Яндекс Книги, а также проверить гипотезу о том, что среднее время активности пользователей в Санкт-Петербурге больше, и это различие статистически значимо.

---

# Навыки и инструменты

- PostgreSQL
- python
- pandas
- matplotlib
- scipy.stats

---


# Общий вывод

Проект разбит на 2 части.  
В части 1 выполнен расчет ключевых метрик активности пользователей в PostgreSQL: MAU авторов, MAU произведений, Retention Rate, LTV, средней выручки прослушанного часа. Затем подготовлены данные для дальнейшей проверки гипотезу в Python.
В части 2 проведена предобработка данных, выполнено сравнение размеров групп пользователей и их статистик, проверена гипотеза с использованием двухвыборочного одностороннего t-теста Уэлча.
