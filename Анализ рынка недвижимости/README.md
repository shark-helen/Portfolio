# Описание проекта

Необходимо помочь агентству недвижимости из Петрозаводска, которое планирует выйти на рынок Санкт-Петербурга и Ленинградской области, выбрать сегмент недвижимости с высоким спросом и подходящий сезон для публикации объявлений, а также доработать дашборд, отображающий информацию об объектах недвижимости в Санкт-Петербурге и Ленинградской области, по техническому заданию от заказчиков.

---

# Навыки и инструменты

- PostgreSQL
- DataLens

---

# Общий вывод

Было проведено исследование данных, решены ad hoc задачи, сформулированы выводы и рекомендации, в аналитический дашборд в соответствии с техническим заданием добавлены новые фильтры и возможности для анализа данных, а также усовершенствовано отображение информации об объектах недвижимости.
