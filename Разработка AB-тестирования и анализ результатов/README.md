# Описание проекта

Требуется рассчитать параметры A/B-теста, который позволит проверить гипотезу команды разработчиков рекомендательных систем развлекательного приложения с функцией «бесконечной» ленты о том, что новый алгоритм рекомендаций будет показывать более интересный контент для каждого пользователя, и проанализировать его результаты.

---

# Навыки и инструменты

- python
- pandas
- matplotlib
- statsmodels.stats.power
- statsmodels.stats.proportion

---

# Общий вывод

Был проведен исследовательский анализ исторических данных с визуализацией, выполнена подготовка к А/В-тесту (определение целевой метрики, необходимого размера выборки и длительности проведения теста), мониторинг А/В-теста (проверка распределения пользователей по группам, пересечений, равномерности распределения по категориальным переменным), проверка результатов A/B-теста и подготовка выводов по результатам.
