# Описание проекта

Необходимо визуализировать ключевые метрики для сервиса доставки еды, разработать дашборд, который с разных сторон отразит состояние клиентской базы, и на основе этого дашборда составить аналитический отчёт.

---

# Навыки и инструменты

- DataLens

---

# Общий вывод

Были подготовлены QL-запросы в DataLens для визуализации бизнес-метрик (DAU, Conversion Rate, средний чек, LTV, Retention Rate), разработан дашборд, подготовлена аналитическая записка.
