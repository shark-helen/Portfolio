# Описание проекта

Необходимо выяснить, какая доля игроков онлайн-игры «Секреты Темнолесья» покупает внутриигровую валюту за реальные деньги и есть ли зависимость доли платящих игроков от расы персонажа, а также детально изучить, как происходит покупка эпических предметов внутри игры.
