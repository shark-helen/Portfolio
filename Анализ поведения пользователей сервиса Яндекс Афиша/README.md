# Описание проекта

Необходимо провести анализ поведения пользователей сервиса Яндекс Афиша, а именно:
1. Разработать аналитический дашборд в Yandex DataLens, с помощью которого можно отслеживать динамику ключевых бизнес-показателей, анализировать популярность мероприятий и структуру выручки в разрезе категорий событий и устройств.
2. Провести исследовательский анализ данных в Python для подготовки выводов об изменении пользовательских предпочтений и популярности событий осенью 2024 года, а также проверки гипотезы о разнице в поведении пользователей с мобильных и стационарных устройств.

---

# Навыки и инструменты

- PostgreSQL
- DataLens
- python
- pandas
- matplotlib
- seaborn
- scipy.stats

---


# Общий вывод

Проект разбит на две части.  
В части 1 проведен анализ данных с помощью SQL и создан дашборд в DataLens.  
В части 2 проведены предобработка и исследовательский анализ данных, проверены две гипотезы относительно активности пользователей мобильных и стационарных устройств за осенний период с использованием двухвыборочного одностороннего t-теста Уэлча и теста Манна-Уитни.
