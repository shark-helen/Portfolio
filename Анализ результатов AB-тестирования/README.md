# Описание проекта

Необходимо оценить корректность проведения A/B-тестирования новой версии сайта интернет-магазина, в котором продаются геймифицированные товары для тех, кто ведёт здоровый образ жизни, и проанализировать его результаты.

---

# Навыки и инструменты

- python
- pandas
- matplotlib
- statsmodels.stats.power
- statsmodels.stats.proportion

---


# Общий вывод

Выполнена оценка корректности проведения A/B-теста: соответствие требованиям технического задания, равномерность распределения пользователей по группам теста, отсутствие пересечений; проведена оценка результатов с использованием Z-тест пропорций.
