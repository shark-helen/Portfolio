# Описание проекта

Необходимо изучить историю продаж игр в начале XXI века за период с 2000 по 2013 год, провести категоризацию данных по оценкам и выделить топ-7 платформ по количеству игр, выпущенных за весь требуемый период.

---

# Навыки и инструменты

- python
- pandas

---

# Общий вывод

Была проведена предобработка данных, преобразование типов данных, проверка и обработка пропущенных значений, нормализация, проверка явных и неявных дубликатов, категоризация данных по оценкам пользователей и критиков, выделены топ-7 платформ по количеству игр, подготовлены выводы.
